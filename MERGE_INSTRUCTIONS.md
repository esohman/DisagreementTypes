# Merge instructions

This archive contains **additions** for the existing DisagreementTypes repository.

1. Copy `README.md`, `LICENSE`, `DATA_LICENSE.md`, `requirements.txt`, and `CITATION.cff` into the repository root.
2. Copy `data/README.md` into the repository's `data/` directory.
3. Copy `scripts/00_run_all.py` and `scripts/08_make_figures.py` into `scripts/`.
4. Keep the existing analysis scripts `01`--`07`; they are not duplicated in this archive.
5. Copy the `outputs/` directory scaffold if it does not already exist.
6. Replace `[repository URL]` in `CITATION.cff` after the repository has a permanent public URL.
7. Confirm that CC BY 4.0 is the intended license for the TOMATS annotation/derived tables before public release.
